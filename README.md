# MicroCAD

## Описание
MicroCAD — консольный редактор C++17, созданный по принципам ООП и паттернов проектирования. Проект имитирует базовую функциональность систем автоматизированного проектирования (САПР).

## Возможности
- Создание и редактирование примитивов: **Точка**, **Линия**, **Круг**
- Перемещение и масштабирование фигур
- Сериализация в JSON (сохранение/загрузка чертежей)
- Модульное тестирование (Google Test, 15+ тестов)

## Технологии
| Компонент | Технология |
|-----------|-----------|
| Язык | C++17 |
| Сериализация | nlohmann/json |
| Тесты | Google Test |
| Сборка | MSVC/cl.exe + tasks.json |

## Структура проекта
├── include/ # Заголовочные файлы

├── gui/ # Qt виджеты

├── tests/ # Модульные тесты

├── data/ # Сохранённые чертежи (JSON)

├── main.cpp # Консольная версия

└── main_qt.cpp # GUI версия
